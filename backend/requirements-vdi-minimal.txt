# ============================================================================
# FPT RAG — SLIM / VDI profile (NO local models, NO torch).
# ============================================================================
# Use this when the VDI blocks large downloads or has no GPU. Embeddings AND
# generation run through the OpenAI-compatible aiportalapi gateway, so no BGE-M3
# / reranker weights are needed.
#
#   pip install -r requirements-vdi-minimal.txt
#
# Then set in .env (see requirements.txt step 2B for the full list):
#   RAG_EMBEDDER_BACKEND=openai
#   RAG_EMBEDDING_API_BASE_URL=https://<aiportalapi-host>/v1
#   RAG_EMBEDDING_DIM=1536
#   RAG_LLM_PROVIDER=openai
#   RAG_LLM_BASE_URL=https://<aiportalapi-host>/v1
#   RAG_LLM_MODEL=gpt-4o-mini
#   OPENAI_API_KEY=<aiportalapi key>
#
# What you give up vs. the full profile:
#   - The cross-encoder reranker is unavailable -> the pipeline uses the lexical
#     fallback reranker. Retrieval still works (dense + BM25 + RRF); ranking
#     precision is lower. Add sentence-transformers + torch later if the VDI
#     allows it to restore bge-reranker-v2-m3.
#   - Token length caps use a heuristic instead of the real tokenizer.
# ============================================================================
