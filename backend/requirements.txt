# ============================================================================
# FPT RAG — BACKEND DEPENDENCIES  +  "WHAT TO DO ON THE COMPANY VDI" PLAYBOOK
# ============================================================================
#
# The rag/* package imports and runs its pure logic with NONE of these installed
# (it falls back to in-memory / heuristic / extractive backends). You install
# deps to turn those fallbacks into the real components.
#
# TWO install profiles:
#   • requirements.txt              (this file) — FULL: local BGE-M3 + reranker.
#                                    Needs ~4 GB of Hugging Face model downloads
#                                    and a torch build.
#   • requirements-vdi-minimal.txt  — SLIM: NO local models. Embeddings + LLM go
#                                    through the OpenAI-compatible aiportalapi
#                                    gateway. Best when the VDI blocks big
#                                    downloads or has no GPU.
#
# ----------------------------------------------------------------------------
# AFTER YOU PUSH THE CODE TO THE VDI — do this, in order:
# ----------------------------------------------------------------------------
# 1. Find out what the VDI allows:
#      - Can you `pip install` from PyPI, or only an internal mirror?
#      - Can the box reach huggingface.co for model downloads (~4 GB)?
#      - Is there a GPU?  python -c "import torch; print(torch.cuda.is_available())"
#      - What is the aiportalapi base URL + API key?
#        (No Redis needed — cache is in-process, session memory is SQLite.)
#
# 2. Pick a profile:
#      A) Downloads allowed & disk/GPU ok  ->  pip install -r requirements.txt
#      B) Downloads blocked / no GPU       ->  pip install -r requirements-vdi-minimal.txt
#         then in .env set:
#           RAG_EMBEDDER_BACKEND=openai
#           RAG_EMBEDDING_API_BASE_URL=https://<aiportalapi-host>/v1
#           RAG_EMBEDDING_DIM=1536             # match the API embedding model
#           RAG_LLM_PROVIDER=openai
#           RAG_LLM_BASE_URL=https://<aiportalapi-host>/v1
#           RAG_LLM_MODEL=gpt-4o-mini
#           OPENAI_API_KEY=<aiportalapi key>
#      C) Air-gapped: mirror the wheels internally; for profile A also pre-download
#         the BGE-M3 + reranker snapshots and point RAG_EMBEDDING_MODEL /
#         RAG_RERANKER_MODEL at the local paths.
#
# 3. Configure:   cp .env.example .env   and fill in the values.
#
# 4. Verify offline first (no models/keys needed):
#      python tests/run_all.py
#      python eval/security_pass.py
#
# 5. Establish the REAL eval baseline once models/LLM are reachable:
#      python eval/evaluate.py --real --update-baseline
#
# 6. Run it:
#      uvicorn api.main:app --host 0.0.0.0 --port 8000
#      # or the whole stack:  docker compose up --build
#
# 7. Production hardening (see .env.example / api/auth.py):
#      RAG_ALLOW_BODY_IDENTITY=false         # trust only SSO proxy headers
#      RAG_PROXY_SHARED_SECRET=<secret>      # must match nginx X-Proxy-Secret
#      RAG_ADMIN_PRINCIPALS=group:rag-admin  # who may ingest/delete
#      RAG_CORS_ORIGINS=https://<frontend>
#      (cache/memory are serverless — nothing to provision)
# ============================================================================
